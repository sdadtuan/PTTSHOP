# P0-1 và P0-3 — sao lưu rồi triển khai `fix/remove-demo-credentials`

Chưa push. Server chỉ `git fetch` được sau khi nhánh có trên `origin`. Việc push chờ anh Tuấn duyệt. Triển khai chỉ chạy sau câu **OK deploy**.

Không chạy seed. Script không dùng `git reset --hard`, `git clean`, `migrate reset` hay `db push`.

## Trước khi triển khai

1. Anh duyệt `deploy/update.sh`.
2. Anh nói rõ được push. Lệnh push (chưa chạy):

```bash
git push -u origin fix/remove-demo-credentials
```

3. Trên VPS, xác nhận user dịch vụ:

```bash
systemctl show pttshop -p User
```

## P0-1 và triển khai mã

`deploy/update.sh` tự làm P0-1 rồi mới đổi mã:

- dừng nếu thiếu `DEPLOY_BRANCH`;
- dừng nếu `/var/www/pttshop` còn thay đổi chưa commit;
- sao lưu `/var/www/pttshop/data/prod.db` vào `/var/backups/pttshop/prod-<TS>.db` và chỉ tiếp tục khi `PRAGMA integrity_check` in `ok`;
- `git fetch`, `git checkout` nhánh, `git merge --ff-only`;
- `npm ci`, `prisma migrate deploy`, `npm run build` bằng user của dịch vụ;
- `systemctl restart pttshop`;
- kiểm tra `http://127.0.0.1:3400/` và `/dang-nhap` đều trả 200.

Nếu một bước lỗi, script in hướng dẫn quay lui về commit trước và bản sao lưu vừa tạo. Script không tự quay lui.

```bash
cd /var/www/pttshop
DEPLOY_BRANCH=fix/remove-demo-credentials ./deploy/update.sh
```

Sau đó mở trang chủ và `/dang-nhap`. Trang đăng nhập không còn gợi ý tài khoản. `/demo-v2` trả 404.

## P0-3 · Đổi admin và AUTH_SECRET

Chỉ làm sau khi script triển khai xong. Gõ mật khẩu bằng `read -s`. Không đặt mật khẩu trên dòng lệnh. Mật khẩu cần ít nhất 12 ký tự, có chữ hoa, chữ thường và số.

```bash
cd /var/www/pttshop
read -r -p "ADMIN_EMAIL: " ADMIN_EMAIL
read -r -s -p "ADMIN_PASSWORD (không hiện khi gõ): " ADMIN_PASSWORD; echo
export ADMIN_EMAIL ADMIN_PASSWORD
sudo -E -u "$(systemctl show pttshop -p User --value)" npm run rotate-admin
unset ADMIN_EMAIL ADMIN_PASSWORD
```

Script in `Đã cập nhật admin <email>; đã khoá N tài khoản demo.` Không in mật khẩu. Hai tài khoản demo bị xoá mật khẩu và hạ vai trò `CUSTOMER`. Đơn hàng không bị xoá.

Đổi `AUTH_SECRET` để huỷ mọi phiên cũ. Giá trị mới không gửi qua chat.

```bash
openssl rand -base64 32
sudo systemctl cat pttshop
sudo systemctl edit pttshop
sudo systemctl restart pttshop && systemctl status pttshop --no-pager
```

Trong `systemctl edit`, thêm vào `[Service]`:

```
Environment=AUTH_SECRET=<giá trị vừa tạo>
```

Chỉ làm vậy nếu unit chưa lấy `AUTH_SECRET` từ `EnvironmentFile=`. Nếu đang dùng file môi trường của dịch vụ, sửa đúng file đó rồi restart. Không dán giá trị vào tài liệu hay chat.

Kiểm tra chỉ đọc, không thử đăng nhập bằng tài khoản demo:

```bash
sudo -u "$(systemctl show pttshop -p User --value)" sqlite3 /var/www/pttshop/data/prod.db \
  "SELECT email, role, CASE WHEN password IS NULL THEN 'locked' ELSE 'has-password' END FROM User WHERE email IN ('admin@vizfas.vn','khach@vizfas.vn');"
```

Kỳ vọng: cả hai dòng `CUSTOMER` và `locked`. Admin mới đăng nhập được. Phiên cũ hết hiệu lực sau khi `AUTH_SECRET` đổi. `systemctl is-active pttshop` là `active`.
