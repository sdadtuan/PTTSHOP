# P0-1 và P0-3 — sao lưu rồi triển khai `fix/remove-demo-credentials`

Chỉ chạy sau khi anh Tuấn nói đúng câu **OK deploy**. Không dùng `git reset --hard` trên máy chủ. Không chạy seed.

`deploy/update.sh` chưa có trong nhánh này. Không tự tạo script deploy khi chưa được duyệt nội dung script.

## P0-1 · Sao lưu `prod.db` (làm lại ngay trước khi triển khai)

Chạy trên VPS với quyền sudo. Lệnh chỉ tạo bản sao, không sửa dữ liệu ứng dụng.

```bash
command -v sqlite3 || sudo apt-get install -y sqlite3
sudo install -d -m 700 /var/backups/pttshop
TS=$(date +%Y%m%d-%H%M%S)
sudo sqlite3 /var/www/pttshop/data/prod.db ".backup '/var/backups/pttshop/prod-$TS.db'"
sudo sqlite3 "/var/backups/pttshop/prod-$TS.db" "PRAGMA integrity_check;"
sudo sha256sum "/var/backups/pttshop/prod-$TS.db" | sudo tee "/var/backups/pttshop/prod-$TS.db.sha256"
ls -lh /var/backups/pttshop/
```

`PRAGMA integrity_check` phải in `ok`. Nếu khác `ok`, hoặc đĩa không đủ chỗ, dừng và không triển khai.

## P0-3 · Triển khai, đổi admin, đổi AUTH_SECRET

1. Xác nhận user chạy dịch vụ, rồi triển khai đúng nhánh:

```bash
systemctl show pttshop -p User
cd /var/www/pttshop
DEPLOY_BRANCH=fix/remove-demo-credentials ./deploy/update.sh
```

Sau đó mở trang chủ và `/dang-nhap`. Trang đăng nhập không còn gợi ý tài khoản.

2. Đổi admin. Gõ mật khẩu bằng `read -s`. Không đặt mật khẩu trên dòng lệnh. Mật khẩu cần ít nhất 12 ký tự, có chữ hoa, chữ thường và số.

```bash
cd /var/www/pttshop
read -r -p "ADMIN_EMAIL: " ADMIN_EMAIL
read -r -s -p "ADMIN_PASSWORD (không hiện khi gõ): " ADMIN_PASSWORD; echo
export ADMIN_EMAIL ADMIN_PASSWORD
sudo -E -u "$(systemctl show pttshop -p User --value)" npm run rotate-admin
unset ADMIN_EMAIL ADMIN_PASSWORD
```

Script in `Đã cập nhật admin <email>; đã khoá N tài khoản demo.` Không in mật khẩu. Hai tài khoản demo bị xoá mật khẩu và hạ vai trò `CUSTOMER`. Đơn hàng không bị xoá.

3. Đổi `AUTH_SECRET` để huỷ mọi phiên cũ. Giá trị mới không gửi qua chat.

```bash
openssl rand -base64 32
sudo systemctl cat pttshop
sudo systemctl edit pttshop
sudo systemctl restart pttshop && systemctl status pttshop --no-pager
```

Trong `systemctl edit`, thêm vào `[Service]`:

```
Environment=AUTH_SECRET=<giá trị vừa tạo>
```

Chỉ làm vậy nếu unit chưa lấy `AUTH_SECRET` từ `EnvironmentFile=`. Nếu đang dùng file môi trường của dịch vụ, sửa đúng file đó rồi restart. Không dán giá trị vào tài liệu hay chat.

4. Kiểm tra chỉ đọc, không thử đăng nhập bằng tài khoản demo:

```bash
sudo -u "$(systemctl show pttshop -p User --value)" sqlite3 /var/www/pttshop/data/prod.db \
  "SELECT email, role, CASE WHEN password IS NULL THEN 'locked' ELSE 'has-password' END FROM User WHERE email IN ('admin@vizfas.vn','khach@vizfas.vn');"
```

Kỳ vọng: cả hai dòng `CUSTOMER` và `locked`. Admin mới đăng nhập được. Phiên cũ hết hiệu lực sau khi `AUTH_SECRET` đổi. `systemctl is-active pttshop` là `active`.
